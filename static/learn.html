What is a Bridge (Critical Connection)?

In an undirected connected graph, an edge is called a Bridge (or Critical Connection) if and only if:

This means that for any two vertices connected by a bridge, there is no alternative path between them other than the edge itself

Think of real-world networks:

  • Road network: If this single highway collapses, island towns are stranded.
  • Data centers: If this fiber optic line is severed, server clusters can no longer communicate.
  • Single Point of Failure (SPOF): Any edge that has no alternative bypass path.

Space and Time Complexity: Why Tarjan is Asymptotically Optimal

❌

Naive "Delete & Test" Method

O(E × (V + E))
⏱️ Time Complexity: O(E × (V + E)) = O(V·E + E²)
  • Outer Loop: Must iterate through all $|E|$ edges in the graph.
  • Inner Traversal: For each edge removed, a full BFS or DFS traverses up to $|V|$ nodes and $|E|-1$ edges, taking $O(V + E)$ time.
  • Dense Graphs ($E \approx V^2$): Total time degrades to $O(V \cdot V^2 + V^4) = \mathbf{O(V^3)}$ or worse!
  • On LeetCode 1192 ($V=10^5, E=10^5$): Operations $\approx 10^5 \times 2\cdot 10^5 = 20,000,000,000$ (20 Billion). Results in immediate Time Limit Exceeded (TLE).
💾 Space Complexity: O(V + E)
  • Adjacency Storage: $O(V + E)$ to represent graph tracks/edges.
  • Auxiliary Space: $O(V)$ for BFS queue and visited boolean array.
⚡

Tarjan's Single-Pass Algorithm

O(V + E)
⏱️ Time Complexity: O(V + E) [Linear & Optimal]
  • Single Traversal: Every vertex is entered and exited exactly once $\to O(V)$.
  • Edge Inspection: Each undirected edge is traversed exactly twice (once from each endpoint) $\to \sum \deg(v) = 2|E| \implies O(E)$.
  • Zero Edge Deletions: Never deletes any edges or re-traverses the graph.
  • On LeetCode 1192 ($V=10^5, E=10^5$): Operations $\approx 10^5 + 10^5 = 200,000$ (0.2 Million). Executes in ~15 milliseconds (Instant).
💾 Space Complexity: O(V) Auxiliary Memory
  • Discovery Time Array: disc[] of size $V \to O(V)$.
  • Lowest Reachable Array: low[] of size $V \to O(V)$.
  • Recursion Call Stack: Up to $O(V)$ in the worst-case (skewed chain graph $0-1-2-\dots-N$), or $O(H)$ where $H$ is the DFS tree height.
  • Adjacency Map: $O(V + E)$ required to store connections.
Metric Naive "Delete & Test" Tarjan's DFS Algorithm Why It Matters
Worst-Case Time $O(E \times (V + E))$ $O(V + E)$ Tarjan is linear; Naive is quadratic or cubic.
Auxiliary Space $O(V)$ (Queue & Visited) $O(V)$ (disc, low & Stack) Both require minimal $O(V)$ extra memory beyond graph storage.

The Secret: Tree Edges vs. Back Edges

When Depth-First Search visits an undirected graph, it organizes all nodes into a DFS Spanning Tree. Every edge in the graph falls into one of two categories:

1. Tree Edges (Forward exploration)

An edge to a node that has never been visited before (disc[next] == 0).

Tree edges form the backbone hierarchy of our DFS tree: Parent $u \to$ Child $v$.

2. Back Edges (The Escape Cycles!)

An edge connecting a descendant back to an already-visited ancestor (excluding the immediate parent).

A back edge creates an alternative bypass route (a cycle!).

💡

Fundamental Theorem: Can a Back Edge ever be a Bridge?

NEVER! A back edge connects a node back to an ancestor that was already reached through the tree. Even if you remove the back edge, the tree path still connects them! Therefore, ONLY TREE EDGES CAN POSSIBLY BE BRIDGES.

4

The Two Arrays: `disc[]` and `low[]`

To mathematically check whether an escape route exists from a child's subtree, Tarjan assigns two numbers to each node $u$:

disc[u] (Discovery Time) Timestamp

The clock timestamp of when DFS first set foot on node $u$.

disc[curr] = time++;

If disc[u] == 0, the node has not yet been visited. Once assigned, disc[u] never changes.

low[u] (Lowest Reachable) Escape Anchor

The lowest discovery timestamp reachable from $u$ (or from $u$'s descendants) using tree edges and at most one back edge.

low[curr] = disc[curr]; // initially

If $u$'s subtree can reach an earlier ancestor via a cycle, low[u] shrinks to that ancestor's timestamp!

How does `low[curr]` get updated during the loop over `edgeMap.get(curr)`?

Case 1: Neighbor is unvisited child (Tree Edge)

We recursively run dfs(next, curr). When the child finishes and backtracks to us:

low[curr] = Math.min(low[curr], low[next]);

"Whatever highest ancestor my child can escape to, I can also escape to!"

Case 2: Neighbor already visited (Back Edge)

If next != prev, we found a cycle connecting us back to an ancestor:

low[curr] = Math.min(low[curr], disc[next]);

"I have a direct back-door jumping up to node next!"

5

The Moment of Truth: Why `low[next] > disc[curr]`?

The Golden Tarjan Condition
if (low[next] > disc[curr])

Edge (curr, next) is guaranteed to be a CRITICAL BRIDGE!

Interactive Escape Route Visualizer

Toggle the cycle back-edge to see how `low[child]` changes and flips the bridge status!

🚨 NO ESCAPE ROUTE (Bridge!)
disc[curr=1] = 2
low[next=3] = 4
low[3] (4) > disc[1] (2) → TRUE!

Node 3 and its children (4, 5) have zero connections back up to node 1 or above. Edge (1, 3) is their ONLY link to the rest of the graph. Cut it, and {3, 4, 5} are trapped forever!

Comparison What it means for child $v$ Is $(u, v)$ a Bridge?
low[v] < disc[u] $v$'s subtree reaches an ancestor visited before $u$. An escape cycle loops around $u$! No (Safe cycle)
low[v] == disc[u] $v$'s subtree can loop back to $u$ itself. A cycle passes through $u$! No (Alternative path exists)
low[v] > disc[u] The earliest node $v$ can reach was discovered after $u$. $v$ cannot reach $u$ or above without edge $(u, v)$! YES! CRITICAL BRIDGE

Line-by-Line Java Solution Walkthrough

Here is your exact Java solution with the logical reason behind every single line annotated:

// 1. Initialize discovery time, low-link array, timer, and adjacency map
class Solution {
int[] disc, low;
int time = 1; // 1-based discovery clock
List<List<Integer>> ans = new ArrayList<>();
Map<Integer, List<Integer>> edgeMap = new HashMap<>();
// 2. Build graph & trigger DFS
public List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
disc = new int[n]; low = new int[n];
for (int i = 0; i < n; i++) edgeMap.put(i, new ArrayList<>());
for (List<Integer> conn : connections) {
edgeMap.get(conn.get(0)).add(conn.get(1));
edgeMap.get(conn.get(1)).add(conn.get(0)); // Undirected
}
dfs(0, -1); // Start DFS from node 0 with no parent (-1)
return ans;
}
// 3. The Core Tarjan DFS Function
public void dfs(int curr, int prev) {
disc[curr] = low[curr] = time++; // Timestamp discovery
for (int next : edgeMap.get(curr)) {
if (disc[next] == 0) { // Unvisited → Tree Edge!
dfs(next, curr); // Explore child
low[curr] = Math.min(low[curr], low[next]); // Child backtracks its lowest
} else if (next != prev) { // Visited ancestor (not parent) → Back Edge!
low[curr] = Math.min(low[curr], disc[next]); // Cycle bypass found!
}
if (low[next] > disc[curr]) // Bridge check!
    ans.add(Arrays.asList(curr, next));
}
}
}

Frequently Asked Interview Questions

❓ Why do we use `disc[next]` instead of `low[next]` on a back-edge? ▼

In else if (next != prev) low[curr] = Math.min(low[curr], disc[next]);, why not low[next]?

By definition, a path escaping a subtree is only valid if it uses at most ONE back edge. If you used low[next], you might be propagating an anchor reached through a second back edge from next, which would falsely suggest that curr has an escape route when in reality cutting an ancestor edge would still isolate it. Using disc[next] guarantees you only reference the direct back edge anchor!

❓ Why do we check `if (next != prev)`? ▼
Because this is an undirected graph! When node 0 calls DFS on node 1, node 1's adjacency list contains node 0. If we didn't skip prev, node 1 would consider the edge back to 0 as a "cycle", setting low[1] = disc[0], which would make it impossible to detect that edge (0, 1) was a bridge!
❓ What if the graph is disconnected initially? ▼
In LeetCode 1192, the problem statement guarantees the graph is connected initially. If a graph could have multiple disconnected components, you simply wrap the DFS in a loop: for (int i = 0; i < n; i++) if (disc[i] == 0) dfs(i, -1);.
